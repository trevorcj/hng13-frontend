# HNG13 Frontend Track

This repository contains the solution for the HNG Internship Stage 0 task for the Frontend Development track.

### Stage 0: Profile Card

The task required building a single, fully **accessible** and **responsive** profile card using **semantic HTML**, **modern CSS (Flexbox/Grid)**, and **Vanilla JavaScript**.

**Live Demo:** [https://trevorsprofilecard.netlify.app/](https://trevorsprofilecard.netlify.app/)

### Stage 1

The task required building multi-page applications. A Contact Us page with form validation, and an About Me page to share reflections.

**Live Demo:** [https://trevorsprofilecard2.netlify.app/](https://trevorsprofilecard2.netlify.app/)
